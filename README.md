# CatalogViewModel

Esta rama corresponde al desarrollo de la subtarea **CatalogViewModel**, perteneciente a la tarea **ViewModels y Estado de UI**.

## Implementación

Se incorpora `CatalogViewModel` para gestionar la lógica asociada al catálogo de productos, incluyendo:

- Listado de productos.
- Filtrado de productos.
- Manejo del estado correspondiente al catálogo.

## Rama

`feature/catalog-viewmodel`

Esta implementación se desarrolló de forma independiente para posteriormente integrarse con las demás funcionalidades del proyecto.
